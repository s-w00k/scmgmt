# School Management — browser-only demonstration

This is a **self-contained browser demo based on the v2.4 interface**, using
HTML, CSS and JavaScript. Open `index.html` directly. There is no backend or
MySQL connection in this package. See `START-HERE.txt` for logins and usage.

The application contains fictional browser-local sample classroom data. A
browser-side API adapter provides additional fictional historical trend,
semester risk, report-card, account, and active-period examples.

All data saved here is browser-local. Do **not** use this build for real pupil
records, authentication, shared operations, or production deployment.

Default teacher login: `schoolteacher` / `123456` (display name remains Michael Hong). Existing browser demo teacher accounts using `michaelhong` are migrated on load.
